# Hydragen

WireGuard VPN + 3x-ui proxy panel with Traefik reverse proxy and xray Reality camouflage.

## Architecture

```
Port 443 (xray Reality, host network)
  +-- Valid Reality client --> xray proxy
  +-- Non-client --> dest: 127.0.0.1:8444 (nginx SNI router)
        +-- SNI matches DOMAIN --> 127.0.0.1:8443 (Traefik) --> WG-Easy
        +-- default            --> cover site (camouflage)

Port 15672 (Traefik, panel entrypoint)
  +-- DOMAIN:15672 --> 3x-ui panel

Port 80 (Traefik)
  +-- Let's Encrypt ACME HTTP challenge
  +-- HTTP --> HTTPS redirect

Port WG_PORT/udp (WireGuard)
  +-- VPN tunnel
```

## Services

| Service | Purpose | Access |
|---------|---------|--------|
| **Traefik** | Reverse proxy, TLS termination (Let's Encrypt) | Internal |
| **WG-Easy** | WireGuard VPN with web UI | `https://DOMAIN` (via Reality fallback) |
| **3x-ui** | Xray proxy panel | `https://DOMAIN:15672` |
| **SNI Router** | nginx stream proxy, splits Reality fallback traffic by SNI | Internal (port 8444) |

## Quick Start

```bash
sudo ./deploy.sh
```

The wizard will prompt for domain, email, admin credentials, WireGuard settings, and the Reality cover site.

## 3x-ui Reality Inbound Configuration

After deployment, open the 3x-ui panel at `https://DOMAIN:15672` and create a VLESS inbound with these Reality settings:

| Setting | Value |
|---------|-------|
| Protocol | VLESS |
| Listen Port | 443 |
| Security | Reality |
| Flow | xtls-rprx-vision |
| uTLS | chrome |
| Target | `127.0.0.1:8444` |
| SNI | `COVER_SITE_DOMAIN,YOUR_DOMAIN` |

**Important:** The Target must point to the nginx SNI router (`127.0.0.1:8444`), not directly to the cover site. The SNI field must include both the cover site domain and your own domain.

### How it works

1. **Reality clients** connect to port 443 and are proxied by xray
2. **Non-client traffic** with your domain's SNI is forwarded through the SNI router to Traefik, which serves WG-Easy and other services with valid Let's Encrypt certificates
3. **All other traffic** (probes, scanners) is forwarded to the cover site for camouflage -- the server appears to be a regular web server

## Commands

```bash
# View logs
docker compose logs -f

# Stop all services
docker compose down

# Restart
docker compose up -d

# Reconfigure
sudo ./deploy.sh
```

## Generated Files

| File | Purpose |
|------|---------|
| `.env` | Environment variables (secrets, domain, ports) |
| `sni-router.conf` | nginx stream config for SNI-based routing |
| `traefik-dynamic.yml` | Traefik file provider config for 3x-ui panel routing |

These are generated by `deploy.sh` and should not be edited manually.
